# Reel Studio

نسخه ۳.۰.۰

استودیوی محلی برای ضبط ریل فارسی. سناریو را همین‌جا می‌نویسی، با تله‌پرامپتر می‌خوانی، پاراگراف‌به‌پاراگراف ضبط می‌کنی، و زیرنویس را روی همان لپ‌تاپ تنظیم و روی ویدیو می‌نشانی. بدون OBS، بدون Camtasia، بدون CDN و بدون لاگین.

ایده اولیه از [عرفان](https://www.instagram.com/erfan.digitalll/). توسعه توسط [آرمان](https://www.instagram.com/arman_cursor)، با Cursor و مدل زبانی.

## این ابزار چیست

یک سرور کوچک Node روی لپ‌تاپ، به‌اضافهٔ صفحهٔ مرورگر. مرورگر دوربین، میکروفون، پیش‌نمایش و تله‌پرامپتر را می‌گیرد. سرور فایل سناریو، کلیپ‌ها، بایگانی و رندر زیرنویس را روی دیسک محلی نگه می‌دارد.

هدف یک نفر است: ریل توضیح‌محور فارسی حدود یک دقیقه، برای اینستاگرام، از یک لپ‌تاپ.

## چه کارهایی می‌کند

### سناریو
- نوشتن سناریو داخل خود برنامه (عنوان + متن)
- هر پاراگراف با یک خط خالی جدا می‌شود و می‌شود یک تکهٔ ضبط
- تاکید رنگی روی کلمه یا عبارت (شش رنگ)
- فهرست سناریوها با ویرایش و ورود مستقیم به ضبط
- خواندن سناریوهای `.md` از پوشهٔ تنظیم‌شده (فقط خواندن، هرگز نوشتن داخل آن پوشه)

### داشبورد و دستگاه‌ها
- انتخاب دوربین و میکروفون، با پیش‌فرض‌های ذخیره‌شده
- پیش‌نمایش زنده و متر سطح صدا
- نسبت تصویر: افقی ۱۶:۹، مربع ۱:۱، ریل ۹:۱۶ (کراپ دقیق روی canvas، نه وابسته به هوس درایور دوربین)
- در نسبت مربع و حالت «چند دوربین»، تقسیم قاب عمودی (ستون) یا افقی (ردیف) انتخاب می‌شود
- حالت «چند دوربین» تا چهار منبع همزمان
- «برش دوربین»: تعویض دوربین هر N ثانیه داخل همان ضبط
- «برش اتوماتیک»: حسگر نگاه لوکال. نگاه به لنز یک دوربین همان دوربین را اصلی می‌کند و تا نگاه به دوربین بعدی همان می‌ماند. مدل روی خود صفحه است و به اینترنت وصل نمی‌شود
- اتصال دوربین گوشی روی همان وای‌فای، با تصویر مستقیم WebRTC (سیگنال روی سوکت محلی)
- راهنما فقط تیتر نشان می‌دهد و توضیح هر تیتر در پاپ‌آپ وسط صفحه باز می‌شود

### تله‌پرامپتر و ضبط
- متن راست‌به‌چپ، خط چشم، کلمات تاکیدی رنگی
- سرعت اسکرول، اندازه قلم، فاصله سطر، آینه، بازگشت به اول
- شمارش معکوس سه‌ثانیه‌ای قبل از هر تکه
- Space شروع/توقف، R ضبط مجدد همان پاراگراف، Enter تایید و رفتن به بعدی
- هر تیک روی دیسک می‌ماند؛ تیک قبول‌شده در `session.json` ثبت می‌شود
- تله‌پرامپتر روی گوشی هم قابل دیدن است و با لپ‌تاپ هم‌سرعت می‌ماند
- دکمهٔ پوشه برای باز کردن پوشهٔ همان ضبط در Explorer

### بایگانی و زیرنویس
- صفحهٔ «ضبط‌های قبل» برای باز کردن یا پاک کردن ویدیوی قبول‌شده
- ویرایش زیرنویس: رنگ، پوشش، اندازه، فونت فارسی محلی، هایلایت، کلمه‌به‌کلمه
- جابه‌جایی جای زیرنویس روی تصویر با کشیدن
- خط زمان برای برش کلیپ، صدا، سرعت، و ویرایش کلمه
- «ثبت نهایی» زیرنویس را با ffmpeg روی فایل خروجی می‌سوزاند (`*-caption.mp4`)

### اصول ثابت
- همه‌چیز محلی است. با آداپتور شبکه خاموش هم صفحه باید کار کند (اتصال گوشی فقط روی LAN محلی است)
- UI فارسی و راست‌به‌چپ، کوتاه و خودمانی
- هیچ em dash در متن برنامه، کامیت یا خروجی نیست

## اجرا

پیش‌نیاز روی همین ماشین:

- Node.js
- ffmpeg روی PATH (یا داخل `vendor/ffmpeg`)
- Chrome یا Edge

```bat
start.bat
```

یا:

```bash
node server.js
```

استودیو معمولاً روی `http://127.0.0.1:7180` باز می‌شود. آدرس گوشی روی داشبورد نشان داده می‌شود (HTTPS محلی روی پورت بعدی).

کپی از تنظیمات:

```bash
copy config.example.json config.json
```

مسیر سناریوهای خارجی، پورت، و نام دوربین/میکروفون ترجیحی داخل `config.json` است. خود `config.json` در گیت نیست.

## ساختار کوتاه

```
reel-studio/
  server.js          سرور محلی
  public/            داشبورد، تله‌پرامپتر، گوشی، سناریو، بایگانی، ویرایش زیرنویس
  lib/               پارس سناریو، پل گوشی، ساخت زیرنویس
  manual/            سناریوهای نوشته‌شده داخل برنامه
  takes/             کلیپ‌های خام هر پاراگراف (گیت‌ایگنور)
  out/               خروجی نهایی با زیرنویس (گیت‌ایگنور)
  tools/             تست‌های خودکار فازها
  SPEC.md            سفارش ساخت اولیه
  SESSIONS.md        تصمیم‌های جلسه‌ای که نباید برگردند
```

## این ابزار چه چیزی نیست

ادیتور عمومی ویدیو نیست. تایم‌لاین افکت‌دار، ترنزیشن، موزیک، استریم، آپلود مستقیم به اینستاگرام، یا زیرنویس غیر فارسی داخل محدوده نیست. برای یک مسیر مشخص ساخته شده: نوشتن، خواندن از تله‌پرامپتر، ضبط تکه‌تکه، نشاندن زیرنویس، خروجی گرفتن.

## مجوز و حریم

کد برای استفادهٔ شخصی روی یک لپ‌تاپ است. کلید و مسیر شخصی داخل `config.json` می‌ماند و commit نمی‌شود. پوشهٔ `scripts` خارجی فقط خوانده می‌شود و این ابزار داخلش چیزی نمی‌نویسد.
